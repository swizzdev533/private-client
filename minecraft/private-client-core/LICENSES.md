# Build and runtime dependencies

No dependency listed here is embedded in the produced Private Client Core JAR.

| Component | Pinned version | Use | Distribution |
| --- | --- | --- | --- |
| Minecraft Java Edition | 1.8.9 | Runtime API supplied by the user's legal game installation | Not included |
| Minecraft Forge | 11.15.1.2318 | Runtime mod loader and build-time userdev | Not included |
| ForgeGradle | 2.1-20211118.174922-42 | Build plugin | Not included |
| MCP stable mappings | stable_22 for 1.8.9 | Build-time symbol mappings | Not included |
| Gradle | 2.7 distribution; wrapper generated by 8.9 | Build tool downloaded by the wrapper | Distribution not included; wrapper bootstrap is included |
| Gson | Minecraft/Forge-provided 2.2.4 API | JSON parsing/writing | Not included |
| Log4j API | Minecraft/Forge-provided 2.0-beta9 API | Local logging | Not included |
| JUnit | 4.13.2 | Unit tests only | Not included |
| Hamcrest Core | 1.3 | Transitive test assertion support | Not included |
